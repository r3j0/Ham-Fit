# 운동 프론트 연동

**2026-09-30 최신 계약은 [최신 백엔드 연동](BACKEND-ROLLOUT.md)을 따른다.** 루틴만 `/api/v2/workout-routines/today`로 오늘 생성하며 실제 80% 시청 완료·서버 자정 마감·과거 영상 시청을 지원한다. 아래 단일 `/workouts/today` 생성·50% 중단·명시적 완료 설명은 이전 v1 계약 기록이다. 기존 단일 기록·재생 세션·복구·기록 화면 구조는 재사용한다.

## 2026-10-01 루틴 화면과 종료 흐름

- 오늘의 운동 제목 오른쪽에 시계 아이콘·예상 분과 완료 수/전체 수 배지를 표시한다. 카드에는 제목과 시간 / 횟수·세트 / 시작·이어하기를 3열로 배치한다. 메인은 진행 중인 운동, 다음 미시작 운동, 남은 미완료 운동 순서로 하나를 선택하며 운동 탭은 전체 목록을 표시한다.
- 루틴 영상의 별도 `운동 완료` 버튼을 제거했다. `여기서 종료` 또는 영상 끝에서 저장된 구간과 네이티브 `played` 구간의 합집합을 계산해 80% 이상이면 `운동 방법대로 운동했나요?` 확인창을, 미만이면 미완료 종료 확인창을 띄운다. 탐색 위치와 중복 시청을 더하지 않으며 최종 완료 판정은 서버가 담당한다.
- 80% 이상은 `완료 처리`, 80% 미만은 `종료 확인` 후 `end`를 저장하고 응답을 확인한 뒤 다음 순서의 미완료 영상으로 이동한다. 마지막 영상 뒤에 미완료가 남으면 `/workout` 목록으로 돌아와 `미완료 · 다시 운동하기`로 재시도한다. 모든 영상이 완료됐을 때만 루틴 완료 화면으로 이동한다.
- 저장 응답 유실은 원래 키·본문으로 확인하기 전까지 이동하지 않는다. 새로고침에서도 종료 요청을 복구한 뒤 이동한다. 후속 루틴 조회 실패는 조회만 재시도하고 종료 요청을 새로 만들지 않는다. 지난 루틴과 완료 영상 다시보기는 진행을 기록하거나 자동 이동하지 않는다.

## 2026-10-01 운동 방법과 기록 표시

- 루틴 영상 위의 운동 순번·길이/장비·중복 처방 문구를 제거했다. 서버의 횟수·시간·유지 값과 휴식·세트 수를 `한 세트 → 세트 사이 휴식 → 총 반복` 안내로 표시한다. 데스크톱에서는 영상 오른쪽, 모바일에서는 영상 아래에 배치한다. 제목 아래에는 `아래와 같은 방식으로 운동하세요!`를 강조한다. 기본 요약과 다른 추가 처방 문구는 함께 보존한다.
- 회원의 상태 햄스터는 모바일에서 운동 목록 위, 데스크톱에서 오른쪽 운동 기록 위에 표시한다. 오늘 배정 없음은 눕기, 배정 후 시작 전·진행 중은 러닝, 중단·미진행 항목이 남으면 추욱, 모두 완료면 드링크 자세다. 조회 실패를 추천 전 상태로 해석하지 않는다.
- 마무리 유산소는 영상 카드와 같은 열·최소 높이·간격을 사용한다. 활동과 분은 횟수·세트 열에 표시하며 영상 완료 수에 포함하지 않는다. 메인에서는 계속 숨긴다.
- 메인의 빈 그룹 영역은 숨기고 오늘의 운동·연속 운동 제목에 KSPO Blue를 적용한다. 최근 7일 완료 표시는 사용자 제공 `public/icons/sunflower.png`를 사용한다. 기존 실제 완료 날짜와 접근성 이름은 유지한다.

80% 이상 확인창에는 회원 색상의 열정 햄스터와 `운동 방법대로 운동하고 완료하세요.` 안내를 표시한다. 취소·닫기·Esc는 완료나 다음 영상 이동을 하지 않는다. 서버는 80% 이상 `pause`도 완료로 판정하므로, 확인 전의 해당 일시정지·화면 이탈에서는 `progress`로 실제 구간만 저장한다. `완료 처리` 후에만 종료를 확정하며 원래 키·본문 복구는 유지한다. 이미 완료된 기존 기록은 되돌리지 않는다.

## 화면과 계약

- 가입: 날짜 전용 `dateOfBirth` 필수 입력. 로그인 본문과 인증 응답의 기존 user 타입은 유지한다.
- `/account/settings?tab=birth`: `GET/PATCH /users/me/profile`로 기존 사용자의 생년월일을 보완한다. PATCH에 CSRF 헤더를 보낸다. 현재 만 나이는 서버 값이며 기존 측정 나이에서 생년월일을 추정하지 않는다. 생년월일 조회·저장 실패 중에도 다른 계정 설정을 사용할 수 있으며, 미저장 입력의 이탈 확인 후 내 프로필로 돌아가 로그아웃하거나 기록을 확인할 수 있다.
- `/`, `/workout`: 공통 컴포넌트로 오늘 배정된 운동 목록을 표시한다. 각 행에는 제목·시간·준비물과 시작/이어하기만 제공하고, 완료한 운동은 완료 표시로 바꾼다. 메인의 이력 링크·상시 새로고침 버튼·추천 설명·배정일/상태·저장된 시청량은 제거한다. 운동 탭의 달력과 간이측정 타이머는 유지한다.
- `GET /workouts/history`의 모든 페이지와 `GET /workouts/current` 응답을 ID로 합치고 높은 revision을 선택한 다음 `serverKoreanDate`에 배정된 항목만 표시한다. 첫 이력 조회 중이거나 일부 페이지가 실패하면 전체 목록을 확정하지 않고 로딩/재시도를 제공한다. 단일 current 응답을 여러 운동으로 복제하지 않는다.
- `/workouts/:id`: 각 행의 시작·이어하기가 연결되는 ‘운동 중’ 화면이다. 기존 플레이어로 해당 운동의 실제 배정과 검증된 `playbackUrl`을 읽어 진행을 복원하고, 명시적인 완료 확인 후 운동 목록으로 돌아간다. 과거 미완료 배정도 이 화면에서 이어간다. unavailable, duration_mismatch, 실제 미디어 로드 오류를 구분해 재시도를 제공하며 원본 HTTP URL로 우회하지 않는다.
- `/workouts/history/:date`: 운동 페이지에서 완료한 날짜 셀을 누르면 ‘운동 기록 상세’로 이동한다. 상세 달력은 선택 날짜가 포함된 주간 보기를 기본으로 표시하고 우측 상단의 `주`·`월` 버튼으로 월간 보기와 전환한다. 기간별 운동 일수 문구는 상세에서 숨기고, 각 완료일 아래에는 그날 완료한 영상 길이의 합계를 분·초 단위로 표시한다. 달력 아래에는 한국 시간의 완료 날짜가 일치하는 운동들을 카드 목록으로 보여 준다. 다른 완료 날짜 선택·직접 진입·새로고침·빈 날짜·조회 실패를 처리하며 유효하지 않은 날짜는 404로 표시한다.
- `/workouts/:id/replay`: 날짜별 기록과 전체 이력의 완료 운동은 ‘운동 다시보기’로 연결한다. 기존 플레이어의 읽기 전용 재생을 사용하고 기록의 완료 날짜 상세로 돌아온다. 미완료 운동은 다시보기에서 재생·저장하지 않고 기존 진행 화면으로 안내한다.
- 메인·운동·내 프로필의 페이지 바탕은 흰색이며 카드·메뉴의 KSPO 강조색은 유지한다.
- 운동·이력·날짜별 상세·진행·다시보기·간이측정에는 기존 KSPO Skyblue 테마를 공통 적용한다. 프로필에서 진입하는 이력은 `/account/workouts` 아래에서 공용 화면을 재사용하고 Orange 테마를 상속한다. 날짜별 상세·다시보기·달력 이동·돌아가기·새로고침에도 Orange와 프로필 하단 메뉴를 유지한다. 공용 운동 요약은 날짜만 표시하고 제목 왼쪽에 완료(초록 체크), 진행 중(회색 시계), 그 외 미완료(노랑) 아이콘을 둔다. 아이콘에는 상태별 접근성 이름을 제공한다. 시청 기록·진행 막대·퍼센트·시간은 모바일에서도 한 줄로 표시한다. 서버의 실제 비율·시간을 사용하며 완료 상태라고 100%로 바꾸지 않는다. 운동 중·다시보기 모두 상시 상태 확인 버튼을 제거하고, 다시보기에서는 완료 안내 문구도 숨긴다.
- `/workouts` 및 `/account/workouts`: 같은 이력 화면과 API를 재사용한다. 내 프로필 메뉴는 `/account/workouts`로 진입하며 미완료 운동의 실제 진행은 기존 `/workouts/:id`로 이동한다. 배정일과 최근 수행일을 구분해 표시하고 미시작·미진행·중단·완료 상태를 유지한다. 커서 페이지 실패 시 기존 목록과 커서를 보존한다.

백엔드 PR #9는 아직 사용자당 하루 한 영상을 배정한다. 이번 변경은 프론트만 대상으로 하며, 같은 날짜의 여러 Workout이 이력 API에 내려오면 모두 표시하고 각각 독립적으로 진행한다. 실제 복수 배정 생성과 백엔드 계약 확장은 별도 작업이다.

조회만으로 추천하지 않는다. 오늘 배정이 없는 상태에서 흰 텍스트의 `운동하기` 버튼을 눌러 빈 본문과 UUID 요청 키로 `POST /workouts/today`를 호출한다. 오류 코드에 따라 생년월일·측정 입력·지원 연령을 안내한다. 화면 복귀·60초 간격으로 상태와 서버 날짜를 다시 읽으며 오류 때만 재시도 버튼을 제공한다. 전날 배정을 오늘 목록에 넣지 않는다. 자정을 넘은 미확정 생성 요청은 원래 키로 원래 배정을 확인한 후 새 요청 키로 오늘 배정을 요청한다.

## 플레이어와 저장

`lib/playback-session.ts`가 직렬 전송과 상태 복구를 담당하고 `components/workout-player.tsx`가 브라우저 미디어 이벤트를 연결한다. 추천 계산·진행률·50% 판정은 서버 응답을 사용한다.

- 시작 또는 재개를 서버가 확인한 뒤 재생 컨트롤을 활성화한다. 완료한 영상은 처음부터 다시 볼 수 있으며 재생·탐색·일시정지·화면 이탈에서 진행 이벤트를 전송하지 않는다. 서버 완료 기록과 revision은 보존한다.
- 시청 구간은 네이티브 `HTMLMediaElement.played`에서 읽는다. 탐색 위치 또는 재생 시간의 차이를 시청량으로 만들지 않는다. 약 5초마다, 탐색·일시정지·종료·완료 때 구간을 전송한다. 구간은 요청당 1,000개 이하로 나눈다. 반복·겹침 구간은 서버가 합집합으로 집계한다.
- 일반 진행 저장은 백그라운드에서 처리하며 영상 위에 저장 안내를 넣거나 완료·종료 버튼을 비활성화하지 않는다. 동일 영상 요소·재생 위치를 유지하고 서버 시청 진행률만 갱신한다. 저장 실패나 이전 미확정 요청 복구 때만 안내·재시도를 표시한다. 종료·완료 확인은 기존 요청이 저장된 뒤 전송하고, 복구 중·오류·최종 처리 중에는 재생과 중복 동작을 막는다.
- 영상 종료 안내와 재생·탐색 설명 문구는 표시하지 않는다. 영상 끝의 마지막 구간 저장은 유지하며 영상 검증 불가 때만 `영상 다시 확인하기`를 제공한다.
- `pause`와 자연스러운 영상 끝은 진행 중을 유지한다. `end`는 서버가 50% 미만이면 미진행, 이상이면 중단으로 판정한다. `complete`는 별도 사용자 확인이 있어야 보낸다. 완료에 시청 비율 조건을 추가하지 않는다.
- 서버가 거절한 요청은 최신 상태 확인과 명시적 폐기를 제공한다. 응답을 받지 못한 요청은 폐기하지 않고 같은 키·본문으로 다시 확인한다. 다른 기기에서 완료했다면 서버 완료 상태를 보존하고 후속 진행 쓰기를 중단한다.
- 계정·배정별 요청 큐를 해당 탭의 `sessionStorage`에 전송 전에 저장한다. 재전송은 원래 deviceId·sequence·키·본문을 유지한다. 새 플레이어는 새 UUID 스트림을 사용해 탭 복제나 재진입 시 순서 번호가 충돌하지 않게 한다. 미확정 저장 복구 전에는 재생을 막는다.
- 작성 권한을 잃은 이전 화면의 응답은 새 큐를 지우거나 현재 화면을 갱신하지 않는다. 인증 만료는 큐를 보존하고 명시적 로그아웃·계정 변경은 폐기한다. 토큰과 비밀번호는 저장하지 않는다.
- 화면 이탈·숨김에서 재생을 멈추고 pause를 가능한 경우 동기적으로 큐에 기록한다. 다음 진입에서 남은 큐를 재확인한다. 문서 강제 종료 전 마지막 몇 초, 탭 종료·저장소 삭제 이후 복구는 보장하지 않는다. 저장소가 차단되면 같은 문서의 메모리로 유지한다.

`progress.durationSeconds`는 카탈로그 기준이다. 검증된 실측 길이가 더 길 때만 해당 실측 끝점까지 보내며 서버가 정규화한다. 실제 체력 개선으로 해석할 수 없는 weightAdjustment는 점수·보상으로 표시하지 않는다.

## 실제 완료 기록

운동 달력과 메인 스트릭은 `GET /workouts/history`의 모든 커서 페이지를 읽고 `status=completed`와 유효한 `completedAt`을 가진 기록만 집계한다. 과거 배정을 나중에 완료할 수 있으므로 배정 순서의 첫 페이지만으로 완료일을 추정하지 않는다. 완료 시각은 `Asia/Seoul` 날짜로 변환하고 같은 날 여러 건은 하루로 센다. 오늘 완료하지 않았더라도 어제까지 이어진 스트릭은 유지한다.

홈·운동 페이지·날짜별 운동 기록 상세에서 공유 이력을 조회한다. 완료 확인, 화면 복귀, 60초 간격으로 갱신하며 계정 변경 시 인증 레이아웃이 캐시를 초기화한다. 취소된 이전 요청과 부분 조회 실패는 집계에 반영하지 않는다. 오류는 0일로 표시하지 않고 재시도를 제공한다. 오늘 날짜는 서버 `serverKoreanDate`를 사용하고 이력이 없는 경우에만 브라우저 시계의 한국 날짜를 사용한다. 이력이 커지면 모든 페이지 조회 비용이 증가하므로 추후 백엔드 날짜별 집계 API로 대체할 수 있다.

달력은 조회 전용이며 완료한 날짜 셀만 날짜별 운동 기록 상세로 연결한다. 운동 페이지의 달력 아래에 있던 날짜 설명과 강조 텍스트 링크, 한국 시간 집계 안내와 ‘밑줄은 오늘’ 문구는 제거했다. 오늘 밑줄과 완료일 표시는 유지한다. 상세 페이지에는 같은 달력과 그날 완료한 운동의 카드 목록이 위아래 순서로 표시되고 각 카드는 다시보기로 연결한다. 예시 완료일과 수동 체크는 사용하지 않는다.
