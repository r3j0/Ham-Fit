# 햄피트 프론트엔드

모바일 중심의 국민체력100 측정 기록 웹앱입니다. 계정 설정, 기록 CRUD, 사진 추출 확인, 성인 간이측정과 서버 평가를 표시하는 6축 체력 프로필·리포트를 제공합니다. 기존 디자인 토큰을 사용하며 `메인 / 운동 / 내 프로필` 메뉴는 모바일·데스크톱 모두 하단에 고정합니다. 메뉴는 접근성 이름을 유지한 아이콘만 표시하고, 운동 아이콘은 56px 원형 배경과 28px 아이콘으로 강조합니다. 본문과 고정 저장 버튼은 하단 메뉴 높이와 기기 안전 영역만큼 여백을 확보합니다.

**실제 백엔드 계약은 [연동 문서](BACKEND-INTEGRATION.md)를 확인하세요.** 운동 설정은 PR #8 `87981e8`의 별도 사용자 설정 API에 연결했습니다. PR #6의 `3c9b91c`를 별도 체크아웃하여 간이측정 저장·종목별 평가·최신 다각형을 연결했습니다. 사진 추출 API도 연결했으며 이번 절대악력 변경의 사진 검증은 실제 유료 호출 없이 계약 응답과 서버 검증으로 수행합니다. 프론트에 예시 평가를 넣거나 등급을 계산하는 fallback은 없습니다. 이 브랜치의 과거 백엔드 확장은 되돌렸으므로 마이그레이션을 가져오거나 병합할 대상이 아닙니다.

## 화면과 흐름

- `/login`: 로그인 전 첫 화면으로 초록웨어 크림 빅토리(뒤)·흰웨어 그레이 러닝(앞)·파란웨어 그레이 드링크(뒤)·검은웨어 크림 윗몸(앞)을 왼쪽부터 대각선 교차로 배치합니다. 로그인 후 허용된 복귀 경로나 메인으로 이동합니다.
- `/register`: 생년월일을 함께 입력하며 가입 완료 후 메인을 거치지 않고 `/onboarding`으로 이동합니다.
- `/`: 실제 `isOnboarded`에 따른 등록 안내와 기본 캐릭터의 대기 모션을 표시합니다. 메인 햄스터는 기존 크기에서 20% 축소하고, 아래에 초록웨어 크림 눕·흰웨어 그레이 윗몸·파란웨어 그레이 러닝·검은웨어 크림 안들려를 가로로 배치합니다. 메인과 그룹 사이 간격은 4px이며 그룹 영역에는 배경·테두리를 두지 않습니다. 그룹 그림은 정지된 예시 데이터이며 각각 메인 크기의 1/3 이하입니다. 모바일은 햄스터 → 그룹 햄스터 → 오늘의 운동 → 연속 운동 순서, 데스크톱은 햄스터·그룹을 왼쪽 열에, 오늘의 운동·연속 운동을 오른쪽 열에 배치합니다. 연속 운동은 오늘의 운동과 같은 제목을 카드 밖에 두고, 카드 안에는 요약과 최근 7일 기록을 두 열로 배치하며 기록 링크는 오른쪽에 정렬합니다. 측정 기록·체력 프로필·상세 리포트는 하단 `내 프로필`에서 확인합니다. 오늘 배정된 운동 목록의 시작·이어하기에서 개별 영상 화면으로 이동하며 명시적 완료는 백엔드 PR #9에 연결합니다.
- `/account`: 실제 이메일·가입 경과일·재화를 표시합니다. 상단 우측에는 제공된 SVG의 해바라기씨와 실제 잔액을 둡니다. 백엔드 PR #9 `31278eb`의 닉네임을 표시하며 미설정 계정은 `닉네임`으로 표시합니다. 가입 경과일은 한국 날짜 기준(당일 0일, 앞자리 0 없이 표시)입니다. KSPO Orange 톤과 모바일 80px·데스크톱 128px 얼굴 대기 모션을 사용하고 캐릭터의 흰 배경은 없습니다. 상단 프로필 카드 안에 체력 그래프와 현재·최장 스트릭, 레벨, 컬렉션 수, 총 운동일 리포트를 통합합니다. 활동 수치 다섯 값은 목업이며 실제 운동·보상에 반영하지 않습니다. 실제 가입일에서 계산한 경과일과 총 운동 일수도 같은 리포트에 배치합니다. 프로필 카드 배경은 아래 계정 메뉴와 같은 색이며 내부 여백은 모바일 20px·데스크톱 28px입니다. 표의 항목명은 검은색, 표 배경은 흰색이며 강조 수치·아이콘은 그래프 점과 같은 KSPO Orange를 사용합니다. 모바일은 프로필 아래에 작은 그래프(왼쪽)와 6개 가로 행의 표(오른쪽)를 2열로 배치합니다. 데스크톱은 프로필·그래프·표를 3열로 표시하고 계정 메뉴는 아래에 둡니다. 리포트 제목·예시 문구는 표시하지 않습니다. 측정 상세 리포트는 내 측정 기록에서 회차를 선택합니다.
- `/account/settings`: 이메일 변경·비밀번호 변경·생년월일·닉네임 변경·회원 탈퇴 탭을 제공합니다. 생년월일과 닉네임은 `/users/me/profile`에 해당 필드만 부분 저장하며 세션을 유지합니다. `?tab=birth`와 `?tab=nickname`으로 직접 진입할 수 있습니다. 탭 이동 시 입력을 보존하고 화면 이탈 시 한 번만 확인합니다. 이메일·비밀번호 변경과 탈퇴는 현재 비밀번호를 확인하고 성공 후 모든 탭의 인증과 개인 초안을 정리합니다.
- `/account/preferences`: 운동량(가볍게/기본/충분히)과 운동 목적(등급 개선/체형 관리/기본 체력 증진)을 PR #8의 `/users/me/preferences`로 조회·저장합니다. 변경한 필드만 보내며 목적 미선택 상태에서도 운동량을 저장할 수 있습니다. 로딩·오류·재시도·미저장 이탈 확인을 제공하고 새로고침·재로그인 후 서버 설정을 복원합니다. 추천 운동·커리큘럼 변경은 이 API의 범위에 포함되지 않습니다.
- `/measurements`: 최근 기록, 기간 조회, 추가 등록의 `+` 진입점. 모든 등록 시작점은 `/onboarding`이며 `/measurements/new`도 이곳으로 이동합니다.
- `/onboarding` 및 하위 페이지: KSPO Sky Blue (`#1B99C4`) 톤으로 사진·직접 입력·간이측정 중 등록 방법을 선택합니다. 등록 방법 선택 화면에서는 하단 메뉴와 메뉴용 여백을 숨깁니다. 사진 선택·추출값 확인·직접 입력은 공통 테마를 상속합니다. `나중에 등록하기`는 메인, `내 측정 기록 보기`는 기록 목록으로 이어집니다.
- `/onboarding/manual`: 측정일·만 나이·성별을 필수 기본 정보로 입력합니다. 기존 기록 폼과 초안·미확정 요청 복원을 재사용하며, 실제 저장 후 메인으로 돌아갑니다.
- `/onboarding/photo`: 사진 선택/촬영, JPEG·PNG·WebP/10MiB·디코딩 검증, OpenAI 전송 안내, 추출 요청·취소·재시도. 원문과 추출값을 확인·수정한 뒤 기존 기록 API로 저장합니다. 사진 초안은 직접 입력 초안과 분리합니다.
- `/workout?mode=assessment`: 성인 만 19~64세, 신체정보→교차 윗몸일으키기→YMCA→유연성→확인→저장→기록 상세. 준비 안내·공식 영상·카운트다운·타이머·선택 가능한 박자 안내·재측정·건너뛰기·진행 복원을 제공합니다. **사용자 커리큘럼을 배정·교체·완료하지 않습니다.** 기존 curriculum 쿼리 북마크도 유지합니다.
- `/workout`: 메인과 같은 오늘 배정 운동 목록과 실제 완료 달력을 표시합니다. 각 운동의 시작·이어하기는 `/workouts/:id`의 ‘운동 중’ 화면으로 연결되며 기존 국민체력100 영상 재생·진행 저장·완료 확인 후 목록으로 돌아옵니다. 미배정이면 명시적으로 추천을 요청합니다. 백엔드의 실제 복수 배정은 별도 변경하며 프론트는 동일 날짜의 여러 배정을 모두 표시합니다. 체험용 세트·휴식 타이머는 제거했고 간이측정은 선택한 등록 모드에서만 실행합니다.
- `/measurements/:id`: 해당 회차의 6축 다각형과 접어서 보는 상세 리포트. 기준 미달은 연한 빨강, 3등급은 Orange, 2등급은 진한 Orange, 1등급은 짙은 Orange로 이전·현재·다음 기준을 표시합니다. 한 축에 여러 종목이 있으면 서버가 선택한 대표 종목을 먼저 보여주고 나머지는 개별적으로 펼칩니다. 여러 종목에는 공통·개별 전체 기준표를 두지 않으며, 단일 종목에서만 전체 기준표를 펼칠 수 있습니다. 환산 과정은 접고 출처는 하단 한곳에 모읍니다. 원본 측정값과 결과표 원문 등급을 유지하며, 평가 API가 없거나 잘못된 응답이면 원본 기록을 계속 확인·수정·삭제할 수 있습니다.

[국민체력100 성인 자가측정](https://nfa.kspo.or.kr/measure/self/selectSelfMeasureItem.kspo)의 절차를 정적 운동 정의로 사용합니다. 실제 기록은 사용자 입력만 저장합니다. BMI는 신장·체중이 모두 있을 때만 계산하며 YMCA 10초 맥박 횟수는 ×6하여 bpm으로 저장합니다. 판정용 환산과 등급은 백엔드가 담당합니다. 성인 스텝검사는 같은 기록의 성별·나이·신장·체중이 있으면 VO₂max 추정값과 참고 등급을 표시합니다. 입력이 부족하면 심박수 원본을 저장하고 평가 불가 사유를 안내합니다. 정식 국민체력100 인증을 부여하지 않습니다.

운동 추천·재생·이력의 API 계약과 서버 준비는 [운동 연동 문서](WORKOUTS.md)를 참고하세요. `/workouts`는 운동 영역의 실제 서버 이력입니다. 내 프로필에서는 동일한 화면을 `/account/workouts`로 열어 날짜별 상세(`/account/workouts/history/:date`)·다시보기(`/account/workouts/:id/replay`)까지 Orange와 프로필 하단 메뉴를 유지합니다. 미완료 운동을 이어하면 기존 `/workouts/:id` 운동 화면으로 이동합니다. 운동 페이지의 기록 영역은 달력만 표시하며 완료한 날짜 셀을 누르면 `/workouts/history/:date`의 ‘운동 기록 상세’로 이동합니다. 상세 화면은 달력 아래에 해당 날짜의 운동을 카드 목록으로 표시하고, 각 카드는 `/workouts/:id/replay`의 ‘운동 다시보기’로 연결합니다. 달력과 메인 스트릭은 서버의 완료 시각을 한국 날짜로 환산하며 수동 체크나 예시 기록을 사용하지 않습니다. 다시보기는 기존 완료 기록과 시청 구간을 변경하지 않습니다. 운동 영역과 하위 화면은 KSPO Skyblue 테마를 공유합니다. 프로필·계정 설정·운동 설정·측정 목록/상세/수정·프로필 운동 이력은 KSPO Orange 테마를 공유하며, 하단 바의 배경·아이콘·원형 운동 버튼도 같은 톤을 따릅니다. 운동 요약의 날짜는 날짜만, 상태는 제목 왼쪽의 초록·회색·노랑 아이콘으로 표시하고, 시청 진행 막대는 서버의 실제 비율과 시간을 사용합니다.

## 로컬 실행

먼저 별도의 백엔드 체크아웃에서 해당 브랜치의 README에 따라 API와 개발용 PostgreSQL을 실행합니다. 이 프론트 브랜치의 `backend/`는 main 상태이므로 사용자 확장·OCR·평가 기능이 모두 들어 있다고 가정하지 마세요. 기존 `.env`나 다른 체크아웃의 변경을 덮어쓰지 않습니다.

`frontend/`에서 실행:

```bash
npm ci
# .env.local이 없을 때 .env.example을 복사하여 API 주소 설정
npm run dev
```

- 기본 프론트 `http://localhost:3000`, API `http://localhost:3001/api/v1`.
- `NEXT_PUBLIC_API_BASE_URL`은 브라우저에서 직접 접근할 API 주소입니다. 빌드 시 포함되므로 주소 변경 후 다시 빌드합니다. 비밀 키를 넣지 않습니다.
- 백엔드 `FRONTEND_ORIGIN`을 프론트 origin과 일치시키고 credentials·CSRF 헤더·ETag 노출을 허용합니다. `localhost`와 `127.0.0.1`을 섞지 않습니다. 프론트 API rewrite는 사용하지 않습니다.
- 배포는 프론트와 API를 같은 사이트의 HTTPS로 구성합니다. 쿠키·CORS·프록시 설정은 백엔드 문서를 따릅니다.
- Node.js 24.15 이상. 이 작업의 검증 환경은 Node.js 26.7.0, Next.js 16.3.5입니다.

## 데이터와 인증

측정 값은 Decimal 문자열로 보내고 공란은 제외합니다. 실제 `0`·음수·긴 소수를 보존합니다. `reportedGrade`는 결과표 원문, `items[].evaluation`은 서버의 종목별 판정입니다. 최상위 `evaluation`은 종합 인증 미판정 안내이며 차트 데이터는 `axes`입니다. 프론트가 두 값을 섞지 않습니다.

생성은 작업당 한 `Idempotency-Key`, 수정/삭제는 조회한 ETag의 `If-Match`를 사용합니다. 저장 응답을 잃으면 원래 키·본문을 유지해 재확인합니다. 충돌 때 입력을 보존하고 최신 기록을 확인한 뒤 진행합니다. 인증 만료/로그아웃/계정 전환 뒤 늦은 응답은 무시합니다.

계정·기록별 초안은 탭의 sessionStorage에 보관합니다. 일반 초안은 24시간, 미확정 저장 요청은 결과 확인까지 유지합니다. 명시적 로그아웃·계정 전환 때 지우며 비밀번호·토큰·사진 바이트는 보관하지 않습니다. 저장소 차단 시 같은 문서의 메모리로 대체합니다. 사진 원본은 새로고침 시 사라져도 확인 폼의 값·검토 메모는 복원됩니다.

사용자 상태와 최신 대표 프로필은 측정 변경·다른 탭 변경·화면 복귀 후 재조회합니다. API 오류를 임의의 성공·미등록·평가 등급으로 대체하지 않습니다.
